## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
Generates production-ready optimized assets in the `dist/` directory.

### 4. Instant Standalone Preview
Open `preview.html` directly in any web browser without needing a local Node.js environment.
