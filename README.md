# CleanShot X — Official Website Recreation

A faithful, high-fidelity recreation of the official **[CleanShot X](https://cleanshot.com/)** website built with React 19, Tailwind CSS v4, Framer Motion, and Lucide Icons.

---

## 🚀 How to Run the Website

### Option 1: Live Vite Dev Server
```bash
cd C:\Users\harsh\.gemini\antigravity\scratch\cleanshot-x
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: Production Build & Preview
```bash
npm run build
npm run preview
```

### Option 3: Instant Standalone Browser Preview
Open `preview.html` directly in Google Chrome, Safari, Edge, or Firefox:
`file:///C:/Users/harsh/.gemini/antigravity/scratch/cleanshot-x/preview.html`

## 🎨 Visual Design & Style System

- **macOS / Apple Aesthetic:** Minimal clean white canvas (`#ffffff`), subtle icy-blue gradients, and soft radial glows.
- **Electric Blue Signature:** `#0d44e8` (CleanShot brand blue) for CTAs, focus indicators, and camera lens aperture icon.
- **Typography:** Modern, tightly spaced geometric sans (Inter & Plus Jakarta Sans style) with bold contrast.
- **Realistic macOS Visuals:** 
  - macOS menu bar with active CleanShot drop-down menu
  - Floating Quick Access Overlay with preview thumbnail, drag & drop, and action buttons
  - Realistic Annotation Suite with magnifier loupe, step counters, curved arrows, and token blur/redaction
  - Screen recording HUD with circular webcam bubble, microphone EQ meters, and Studio Mode cursor smoothing
  - Background Tool with real-time gradient and padding presets
  - Text Recognition (OCR) scanner with on-device Apple Neural Engine simulation
